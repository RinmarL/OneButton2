# OneButton (FACTORY ESCAPE)

ひとつの赤いボタンとインダストリアルな装置に隠された謎を解き明かす、全11ステージのブラウザ脱出パズルゲームです。

---

## 🎮 ゲーム概要

画面中央に鎮座する「たったひとつのボタン」。  
しかし、各セクター（ステージ）ごとにボタンと装置の性質・解除条件はまったく異なります。  
触って、動かして、観察して、仕掛けられたギミックの謎を解き明かしてください。

- **総セクター数**: 10セクター ＋ 最終セクター（SECTOR EX : FINAL）
- **操作方法**: マウス操作 / タップ操作（直感的なドラッグ、クリック、長押しなど）
- **オーディオ**: Web Audio API による完全内蔵シンセシス効果音
